*Cách tính (script `sus_score.py` tự tính):* câu lẻ (1, 3, 5, 7, 9) lấy điểm − 1; câu chẵn (2, 4, 6, 8, 10) lấy 5 − điểm;

Bangor và cộng sự, 2009).
